# API compatibility

## Implemented endpoints

| Method | Path | Behavior |
|---|---|---|
| `POST` | `/v1/chat/completions` | Transparently proxies JSON and SSE responses |
| `GET` | `/v1/models` | Transparently proxies the backend model list |
| `GET` | `/healthz` | Gateway process liveness |
| `GET` | `/readyz` | Gateway configuration readiness |
| `GET` | `/metrics` | Prometheus text exposition |

The proxy intentionally does not decode and rebuild Chat Completions payloads. This preserves optional and backend-specific request fields. It removes hop-by-hop HTTP headers and adds standard forwarding headers.

## Streaming

Responses with `Content-Type: text/event-stream` are copied incrementally and flushed after every upstream read. The gateway does not parse or buffer the complete event stream.

Once response headers or tokens have been sent, the gateway cannot replace the response with a JSON error. Mid-stream backend failures therefore appear as a terminated stream.

## Cancellation

The incoming request context is attached to the upstream request. Client disconnects and gateway request deadlines cancel the backend request. Actual compute cancellation also depends on the backend honoring HTTP connection cancellation.

## Errors generated by the gateway

Gateway-generated errors use the OpenAI error envelope:

```json
{
  "error": {
    "message": "the inference backend is unavailable",
    "type": "upstream_error",
    "code": "upstream_error"
  }
}
```

Current mappings:

| Condition | HTTP status | Code |
|---|---:|---|
| Backend unavailable | `502` | `upstream_error` |
| Gateway/backend deadline | `504` | `upstream_timeout` |
| Request canceled before response | `499` | `request_canceled` |
| Internal request construction failure | `500` | `gateway_error` |

Backend status codes and response bodies pass through unchanged.

## Current limitations

- No authentication or tenant policy enforcement yet;
- no token-aware admission or scheduling yet;
- `/readyz` does not actively probe backend health yet;
- streaming idle timeout and exact first-token timeout are not yet implemented;
- OpenAI Responses, Completions, and Embeddings APIs are not yet implemented.
